# DevMatch

DevMatch is a full-stack platform for discovering technical projects and finding teammates based on skills, interests, availability, and project needs.

## Features

- User accounts and authentication
- Developer profiles with skills and interests
- Technical project discovery
- Project creation and management
- Skill-based teammate matching
- Project applications and team invitations
- Persistent user and project data
- RESTful API for frontend/backend communication

## Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- REST APIs

### Database
- PostgreSQL
- Prisma ORM

### Authentication
- JWT
- bcrypt

### Development & Deployment
- Docker
- GitHub Actions
- Git/GitHub
